📳 VibrationTest Pro — тест вибромотора (разные режимы)
Интерактивный инструмент для проверки работы вибромотора в различных режимах: одиночный импульс, серия, непрерывная вибрация, нарастание/затухание, паттерны и сигнал SOS.
Реализован на 7 языках программирования для демонстрации кроссплатформенной работы с системными таймерами и управлением устройствами.

🧠 Концепция
VibrationTest Pro — это утилита для проверки работы вибромотора на устройствах, поддерживающих вибрацию (смартфоны, игровые контроллеры, умные часы). Она позволяет:

✅ Выбирать режимы вибрации из списка: одиночный, серия, непрерывный, нарастающий, затухающий, паттерн «длинный-короткий», SOS и др.

✅ Настраивать длительность и интенсивность (где поддерживается).

✅ Отображать визуальную индикацию в консоли (текстовые импульсы).

✅ Управлять с помощью клавиш или аргументов командной строки.

✅ Зацикливать режим для длительного тестирования.

✅ Работать как на реальных устройствах (через системные API), так и в симуляционном режиме для разработки.

🚀 Как запустить
Каждая версия реализована как консольное приложение. Управление осуществляется через меню или аргументы командной строки. Для реальной вибрации требуются соответствующие библиотеки, но в демонстрационных целях используется симуляция (вывод в консоль).

Python
bash
python vibration_test_python.py
C++
bash
g++ -std=c++17 vibration_test_cpp.cpp -o vibrationtest
./vibrationtest
Java
bash
javac VibrationTestJava.java && java VibrationTestJava
C#
bash
dotnet run
Go
bash
go run vibration_test_go.go
Rust
bash
cargo build --release && ./target/release/vibration_test_rs
JavaScript (Node.js)
bash
node vibration_test_js.js
